# Job Search Criteria (DEMO PERSONA: Alex Rivera, fictional)

Use this file when reviewing job postings, email alerts, or recruiter outreach. Explain the fit rather than producing a keyword score.

## Role Types

**Primary targets:**
- Senior Backend Engineer
- Senior Software Engineer (platform, data, or API focus)
- LLM application engineer (tool calling, evaluation, production integration)

**Secondary targets:**
- Staff Engineer, when the scope is hands-on

## Seniority

- Senior and above; Staff when responsibilities align
- About 12 years of experience
- No entry-level, junior, or associate roles

## IC vs. Management

- Individual contributor or tech lead; no direct people management

## Remote

- Fully remote in the US is required
- Hybrid or on-site roles are excluded

## Employment Type

- Full-time only; skip contract and part-time roles

## Technical Strengths

**Strongest areas:** Python, PostgreSQL, AWS (Lambda, ECS, SQS), event-driven pipelines, REST API design, LLM tool calling with evaluation sets
**Supporting:** TypeScript, React, Django, HL7 v2 integrations

## Stack Fit

- If several must-haves are technologies listed under "Not yet evidenced" in the fact bank (Kubernetes, Go, RAG, fine-tuning), rate the role Possible at best.

## Compensation

- Floor: $160,000. A range qualifies if $160k falls within it.
- If pay isn't disclosed, flag it as unknown; don't exclude.

## Hard Excludes

- On-site or hybrid
- People-manager roles
- Contract or part-time
