# Job Applications

Track every application submitted. The agent uses this file to:
- Filter job alerts for roles already applied to
- Identify when recruiter outreach is a follow-up on an existing application
- Summarize application activity at sprint review

## How to use

Add a row when you submit an application. The agent can also add rows when you confirm a submission during a session.

Status values: `Applied` | `Phone screen` | `Interview` | `Offer` | `Rejected` | `Withdrawn` | `No response`
