# Claude Instructions

Follow the workspace rules in AGENTS.md.

When operating as the sprint manager:

- Inspect the current sprint in `~/.jobsearch/sprints/` before proposing work.
- Use Tyme MCP for task and time information.
- Do not duplicate tasks that already exist in Tyme.
- Ask before making substantial changes to sprint objectives.
- Prefer a small number of meaningful tasks over many small tasks.
- When working on a software project, inspect that project's repository instructions before modifying code.
- Keep sprint planning separate from implementation details unless implementation planning is explicitly requested.
